# Título do jogo: The Anthill Epidemic.

## Narrativa/tema:
“The Anthill Epidemic” é um jogo que se passa em uma epidemia de formigas gigantes . Um laboratório composto por cientistas precisa de substâncias para elaborar a cura das mutações. Mas, para isso ,eles precisam que as fórmulas cheguem até eles.

## Objetivo do jogo:
O objetivo do jogador é entregar suprimentos no laboratório de cientistas para acabar com a epidemia de formigas gigantes.
Para entregar, ele precisa passar por seus inimigos. 

## Ações do jogador:
Anda e coleta itens.

## Inimigos e/ou obstáculos:
Os inimigos do jogador (obstáculos) são formigas mutantes,ele precisa passar pelo labirinto para concluir seu objetivo.


## Itens e coletáveis:
Os itens são frascos com os alimentos necessários para a entrega encontrados na fase 3. Nas fases anteriores,os itens são entregados para o jogador por outro personagem para a jogatina no labirinto

## Condições de vitória:
O personagem precisa entregar no minímo 6 frascos ao laborátorio ao final do jogo  (acumulativo)


## Condições de derrota:
Se o jogador entregar menos de 6 frascos e morrer duas vezes em cada fase.

## Progressão/dificuldade:
As formigas vão sendo adicionadas durante as fases em lugares inusitados.

## Referências visuais/estéticas:
Jogo em 2d (pixelado)
